# Slide-Iterator

## Проблема
Необходимо организовать просмотр изображений в виде слайд-шоу. Изображения хранятся в указанной папке, к-я может иметь вложенные папки. 

## Требуется 
Создать возможность перебора содержимого папок с учетом вложенности и с фильтрацией
